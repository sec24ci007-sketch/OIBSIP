# PROJECT DESCRIPTION: NUMBER GUESSING GAME
The first project I completed is a console-based Number Guessing Game. In this application, the system generates a random number between 1 and 100, and the user is tasked with guessing that number. To make the game interactive, the program provides immediate feedback after each guess by stating whether the guess was too high or too low. To add a layer of challenge, I implemented a limited attempt system where the player must find the number within ten tries. Furthermore, the program calculates a final score based on how quickly the user identifies the correct number.

# TECHNICAL IMPLEMENTATION
This project was developed using the Java programming language within the Visual Studio Code environment. The logic relies on the Java Scanner class to capture user input and the Random class to generate the secret number. The game flow is controlled by a while loop that monitors the number of attempts, while conditional if-else statements handle the comparison logic and score calculations. Version control for this project was managed using Git and the files are hosted here on GitHub.
